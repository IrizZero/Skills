# Habitat Tracker

A field-research web app for wildlife conservation NGOs. Volunteers in remote
locations record animal sightings, GPS coordinates, habitat photos, and
behavioral notes. Researchers back at base aggregate observations across teams,
visualize species distribution on maps, and export datasets to academic
collaborators.

The user base is split: field volunteers (often non-technical, working on
phones offline in low-bandwidth conditions) and researchers (desktop, expect
spreadsheet-style data tables and chart panels). The brand voice is
"grounded, hopeful, evidence-based" — no flashy marketing-style visuals;
think Patagonia + iNaturalist + a touch of academic publication.
