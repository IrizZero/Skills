# Stress Test

Sharpen the user's reasoning without producing a specification, plan, or implementation.

1. Inspect facts that can be discovered from the workspace instead of asking the user to recall them.
2. Identify the highest-leverage unresolved decision: the one on which the most downstream choices depend.
3. Ask exactly one question and wait for the answer.
4. Include your recommended answer and a short reason so the user has a concrete position to challenge.
5. After each answer, update the decision tree. Skip branches that the answer makes irrelevant.
6. Separate factual uncertainties from preference or judgment calls.
7. Stop when the major assumptions and failure modes have been examined, or when the user ends the exercise.

Do not act on the conclusion. If the user wants to proceed, hand back the agreed facts, decisions, and unresolved risks in a short summary.
